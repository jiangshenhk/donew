# 四阶段周期 × AI产业周期修正模型

## 核心原则

宏观四阶段是底层框架，AI属于特殊产业周期变量。

> AI可以让部分资产提前上涨，但不能替代宏观周期判断。

判断市场需要回答：

1. 周期有没有切换？
2. 哪个资产处于自己的优势窗口？
3. 当前仓位应该多少？

---

# 一、②阶段资产表现

|资产|无AI情况下|加入AI后的变化|
|-|-|-|
|小盘股|融资压力大，通常弱势|前期弱，后期等待降息补涨|
|中盘股|承压|优质公司分化|
|大盘股|震荡偏弱|龙头支撑，相对强|
|QQQ/大型科技|通常受高利率压制|AI盈利预期推动提前上涨|
|普通成长股|估值压缩|仍然弱|
|TLT|收益率上涨导致下跌|后期筑底等待降息|
|美元|强势|仍然偏强|
|BTC|流动性不足，弱势|横盘等待③|
|商品|先强后弱|等待经济恢复|

---

# 二、③阶段资产表现

## 无AI情况下

|资产|表现|
|-|-|
|小盘股|经济改善后大幅上涨|
|中盘股|上涨|
|大盘股|估值修复上涨|
|QQQ|利率下降推动上涨|
|债券|收益率下降，债券上涨|
|美元|温和走弱|
|BTC|流动性扩散后上涨|
|商品|后期启动|

## AI参与后的特殊③阶段

|资产|变化|
|-|-|
|QQQ|AI盈利 + 流动性改善，继续领先|
|AI龙头|产业周期与宏观周期共振|
|小盘股|风险扩散后补涨|
|BTC|等待流动性确认后爆发|
|MSTR/MSTU|BTC确认后的增强工具|
|商品|仍偏后期|

---

# 三、当前周期理解

当前模型：

②后期 → ③转换中

AI已经提前推动部分科技资产上涨，但需要观察：

- 30Y长端利率是否下降
- DXY是否温和走弱
- RUT是否持续扩散
- BTC是否接棒

---

# 四、资产轮动顺序

正常路径：

QQQ → BTC → MSTR/MSTU → 商品

AI修正后：

AI龙头/QQQ提前 → 风险扩散 → BTC → 高Beta → 商品

---

# 五、重要原则

> AI是产业周期变量，不改变四阶段宏观周期。

> ②阶段中可以出现结构牛市；③阶段确认需要看到上涨从少数赢家扩散到更多资产。
