# 内容总结分析（视频/文章） — AI 提示词

## 系统角色

```
你是一个专业的内容总结助手。请用中文回复。
```

## 用户提示词模板

```
请对以下{视频/文章}进行总结和深度分析。用中文回复，严格按以下结构：

## 内容概览
简要说明该{视频/文章}的主题、类型和核心内容。

## 📋 核心要点
列出 3-8 个核心观点或重要信息，每条以"**要点：**"开头单独列出。

## 💡 关键结论
总结最终的结论、立场或建议。

## 📊 补充观察
如果有值得关注的细节、数据或案例，请在此补充。

## 🔍 AI 深度分析
从以下角度进行独立的深度分析：
- ✅ 机会信号：正面信号、增长机会、有利因素
- ⚠️ 风险提示：风险、隐患、需要警惕的地方
- 📈 背景补充：相关背景知识、行业趋势、历史脉络
- 🔗 延伸思考：可能引发的进一步思考或值得关注的问题
- 🧠 独特见解：基于内容之外的知识，给出独有的洞察或评价

标题：{标题}
作者：{作者}

原始内容：
{内容文字，最多15000字}
{用户额外说明}
```

## 支持的输入方式

| 模式 | 数据源 | 获取方式 |
|---|---|---|
| 视频（YouTube） | 字幕文本 | `youtubetranscript.com` XML 解析 |
| 视频（B站） | AI 字幕 | B站 API `x/web-interface/view` + `x/player/v2` |
| 文章（网页） | HTML 正文 | fetch + 标签清洗提取 |
| 文章（粘贴） | 用户直接输入 | 跳过解析直接用 |

## 内容截断规则

- 原文超过 15000 字时自动截断，并在尾部标注原长度

## 输出格式

- API 返回 JSON，含 `html`（完整 HTML 报告）、`markdown`、`summaryText`
- HTML 报告为独立页面，深色主题（#0f172a 底色，#fde047 金色标题）
- 涨跌数字用 `<span class="num-pos">` / `<span class="num-neg">` 着色

## 调用方式

- API: `kline_robot_vercel/api/news-summary.js`（`mode=video` / `mode=article`）
- 文件已合并到 news-summary，通过 `mode` 参数路由
- 支持 DeepSeek / OpenAI 双路由
- 默认模型: `deepseek-v4-pro`
